# 酷安隐私说明草稿

时停重视用户隐私，所有管控与统计均在设备本地完成。

## 权限用途

1. 无障碍服务
   - 用途：在非 Root 普通保护模式下识别当前前台应用包名，用于开始、暂停或结束本地计时。
   - 限制：不读取窗口内容、页面节点、文字、输入内容、账号信息或通知内容。
   - 上传：无障碍事件不会上传到服务器。

2. 使用情况访问
   - 用途：读取 Android 系统记录的应用使用时长，用于校准每日累计额度。
   - 上传：使用记录仅在本机计算，不会自动上传。

3. Shizuku（可选）
   - 用途：在用户主动启用“普通保护 + Shizuku”模式后，对已配置且符合安全校验的第三方目标应用执行到限强停。
   - 限制：不提供任意命令入口，不对未配置应用或系统关键应用执行强停。

4. 网络访问
   - 用途：检查 GitHub Releases 更新、打开反馈或说明链接。
   - 上传：不会自动上传规则、统计或诊断数据。

## 本地数据

时停会在本机保存：

- 受控应用规则；
- 应用分组；
- 本地统计与限制触发记录；
- 诊断日志；
- 用户选择的保护模式和界面设置。

这些数据默认保存在本机，不会自动上传。用户通过邮件反馈问题时，可自行选择是否附带诊断日志。

## 适用范围

本应用应仅由设备所有者本人或明确授权的受管设备使用，不应用于未经同意的监控或隐蔽安装。
