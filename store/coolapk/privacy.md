# 酷安隐私说明草稿

时停重视用户隐私，所有管控与统计均在设备本地完成。

## 权限用途

1. 无障碍服务
   - 用途：在非 Root 普通保护模式下识别当前前台应用包名，用于开始、暂停或结束本地计时。
   - 限制：不读取窗口内容、页面节点、文字、输入内容、账号信息或通知内容。
   - 上传：无障碍事件不会上传到服务器。

2. 使用情况访问
   - 用途：读取 Android 系统记录的应用使用时长，用于校准每日累计额度。
   - 上传：使用记录仅在本机计算，不会自动上传。

3. Shizuku（可选）
   - 用途：在用户主动启用“普通保护 + Shizuku”模式后，对已配置且符合安全校验的第三方目标应用执行到限强停。
   - 限制：不提供任意命令入口，不对未配置应用或系统关键应用执行强停。

4. 网络访问
   - 用途：检查 GitHub Releases 更新、打开反馈或说明链接；仅在用户主动配置并执行时连接 HTTPS WebDAV；仅在用户主动从独立限制页请求激励延时时加载广告。
   - 上传：不会自动上传规则、统计或诊断数据。

5. 可选激励广告
   - 用途：用户可在独立限制页主动选择观看激励广告，以申请受规则限制的临时延时。
   - 限制：需要用户先同意隐私说明，且仅在确认奖励回调后生效；每日、单会话、时段、冷却、PIN 和分组限制仍然有效。
   - 数据：广告由 TopOn 提供和加载，具体处理以展示时的第三方隐私说明为准；时停不会将应用使用记录、PIN、规则或诊断日志提交给广告服务。

6. 通知（可选）
   - 用途：在系统允许通知时，展示本机应用使用时长提醒；点击通知仅打开时停的统计页面。
   - 上传：通知内容由本机生成，不会上传使用记录。

## 本地数据

时停会在本机保存：

- 受控应用规则；
- 应用分组；
- 本地统计与限制触发记录；
- 诊断日志；
- 用户选择的保护模式和界面设置。

这些数据默认保存在本机，不会自动上传。用户通过邮件反馈问题时，可自行选择是否附带诊断日志。

用户主动使用“导出配置”时，应用会通过 Android 系统文件选择器生成明文 JSON。文件包含受管应用包名、时间规则、分组和便携界面设置，但不包含 PIN、盐、校验值、生物识别信息、统计、诊断日志、冷却运行状态或临时授权。请用户自行妥善保管导出文件。

用户主动配置并执行 WebDAV 同步时，应用仅连接用户填写的 HTTPS 地址，并在上传前使用用户设置的同步密码对便携配置进行 AES-GCM 加密。WebDAV 凭据仅用于本次传输，不写入便携备份；同步内容同样不包含 PIN、统计、诊断日志或运行状态。

0.11.13 到 Modern 版本的过渡迁移仅在应用私有、禁止系统备份的目录中保存 AES-GCM 加密迁移包。该文件不会由应用上传，导入成功后最多保留30天用于故障恢复。

## 适用范围

本应用应仅由设备所有者本人或明确授权的受管设备使用，不应用于未经同意的监控或隐蔽安装。
