# Obtainium setup

Time Stop does not need a separate central listing for Obtainium. Users can add the GitHub Releases source directly.

Recommended settings:

- Source URL: `https://github.com/Xposed-Modules-Repo/com.liuml.apptimelimiter`
- Source type: GitHub Releases
- APK asset match: `app-time-limiter-v*.apk`
- Package name: `com.liuml.apptimelimiter`

User-facing text:

```text
Use Obtainium to track Time Stop updates from GitHub Releases:

1. Open Obtainium and tap Add App.
2. Use this URL:
   https://github.com/Xposed-Modules-Repo/com.liuml.apptimelimiter
3. Select GitHub Releases as the source.
4. Install the APK named app-time-limiter-v*.apk.
```
